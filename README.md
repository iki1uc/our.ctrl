**Live:** https://iki1uc.github.io/our.ctrl/

## Files
- `index.html` = FINALE v83 — 6 Karten + 3D Würfel + Cache OS Lastung
- `index.old.v82.html` = Backup v82 — Nutzraum-Würfel-OS (läuft)
- `höhe.breite.tiefe.js` = HBT als JS Modul
- `breite.höhe.tiefe.html` = BHT
- `tiefe.höhe.breite.html` = THB
- `tiefe.breite.höhe.html` = TBH
